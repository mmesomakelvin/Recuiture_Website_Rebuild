# Recruiture by EduBridge Academy

## Description
Recruiture is a Nigerian job platform where employers post roles, job seekers find and apply for work, and the EduBridge Academy team recruits on behalf of client companies. Anyone can use it, and verified EduBridge Academy graduates stand out to employers with a graduate badge.

## Problems & Solutions

### Problem 1: Job seekers struggle to find real, current openings
A searchable job board with filters for location, job type, experience and salary in naira, showing only live roles from verified companies, so candidates spend less time on dead ends.

### Problem 2: Trained graduates get lost in a crowded market
EduBridge Academy staff verify graduates and attach the program they completed, so these candidates carry a visible badge and can be surfaced first to employers looking for trained talent.

### Problem 3: Employers waste time managing applications by email
Employers get a simple dashboard to post jobs, review applicants and move them through clear hiring stages, all in one place.

### Problem 4: Some companies want hiring done for them
The EduBridge recruiting team can post and manage roles for client companies, build shortlists and share them, while self-serve employers run their own hiring on the same platform.

### Problem 5: Candidates never know where their application stands
Each application has a status that updates as the employer or recruiter moves it forward, and candidates can track every application from their portal.

## Key Features
- Public job board with keyword search, filters and job detail pages
- Simple apply flow with CV upload and cover letter
- Candidate profiles with experience, education, skills and job preferences
- Verified EduBridge graduate badge with program name and completion date
- Saved jobs and an application tracker for candidates
- Employer company profiles and self-serve job posting
- Hiring pipeline for reviewing and moving applicants through stages
- Recruiter tools for managing client roles and sharing shortlists
- Admin moderation for jobs, companies and users
- Email and in-app notifications for application updates
