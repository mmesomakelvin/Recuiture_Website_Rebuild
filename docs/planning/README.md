# Recruiture planning library

This directory holds reviewable planning material for Recruiture. The Design OS source files in `product/` remain the inputs for screen designs and exports.

| Folder | What belongs here |
| --- | --- |
| `artifacts/` | Reference images, research notes, workshop outputs, and other supporting material. |
| `product-plans/` | Product decisions, scope, release plans, and user journey documents. |
| `architecture/` | Information architecture, navigation, system boundaries, and technical architecture documents. |

Documents here are working drafts until a decision is recorded and reflected in the relevant `product/` specification.
